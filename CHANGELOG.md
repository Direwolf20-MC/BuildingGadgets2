# Changelog

## `1.3.10`

### Added

- `QOL` You can now hold <kbd>Shift</kbd> when using the <kbd>R</kbd> keybinding `(Range)` to reduce the range
- `QOL` When you are using a Gadget that does not support ranges, the <kbd>R</kbd> keybinding `(Range)` will instead rotate the active copy / cut structure

### Fixed

- Button alignment on the various Gadgets radial menus (these would tend to be shifted incorrectly closer to the bottom of the screen)
- Button alignment on the Destruction Gadgets
